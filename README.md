# ALPERIT Mobile

Aplicación móvil desarrollada como parte del Proyecto ABP.

## Descripción

ALPERIT Mobile es una aplicación orientada a la visualización y gestión de vehículos dentro del sistema de peritajes ALPERIT.

Esta primera versión corresponde a la etapa inicial del proyecto y presenta un catálogo de vehículos utilizando datos estáticos y componentes reutilizables.

## Tecnologías utilizadas

- React Native
- Expo
- TypeScript
- Expo Router
- Node.js
- Android Studio

## Funcionalidades implementadas

- Pantalla principal de ALPERIT.
- Listado de vehículos.
- Visualización de imagen, marca, modelo, año y kilometraje.
- Datos estáticos para representar los vehículos.
- Componente reutilizable `VehicleCard`.
- Comunicación entre componentes mediante props.
- Renderizado de vehículos a partir de un listado de datos.
- Scroll vertical para recorrer el contenido.
- Ejecución y pruebas en emulador Android.

## Componentes utilizados

Durante esta primera etapa se implementaron componentes de React Native como:
